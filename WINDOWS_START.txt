FLOW AI КПК — запуск на Windows

1. Установи Python 3.11 или 3.12 с python.org и включи "Add Python to PATH".
2. Распакуй архив.
3. Дважды нажми start.bat.
4. Первый запуск создаст .venv и установит зависимости.
5. Скопируй env.example в .env и впиши ключи. Не публикуй этот файл и не загружай его в GitHub.

Для остановки бота нажми Ctrl+C в окне запуска.

Если Telegram API в твоей сети недоступен, потребуется VPN/прокси.
