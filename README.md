# Flow AI КПК

Telegram-бот на Python + любой OpenAI-совместимый API (по умолчанию бесплатный Gemini), который может участвовать в групповых чатах без обязательного упоминания.

## Возможности

- отвечает на прямые обращения;
- может самостоятельно решить, что пора ответить на обычное сообщение;
- может иногда сам начать короткую реплику;
- хранит последние сообщения каждого чата в SQLite (только для контекста ИИ);
- обсуждает игры и обычные темы;
- личный секретарь `/obz`: перевод, перефразирование, тексты, идеи, удаление сообщений, спам по запросу;
- **безопасность**: выгрузка содержимого личных переписок запрещена навсегда (даже по прямой команде);
- ключи не находятся в исходниках;
- подходит для Northflank и других сервисов, где есть environment variables.

## Переменные

Не добавляй реальные ключи в GitHub.

```text
TELEGRAM_BOT_TOKEN=...
AI_API_KEY=...
AI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
AI_MODEL=gemini-3.5-flash
ADMIN_PASSWORD=...
BOT_NAME=КПК
AUTONOMOUS_MINUTES=45
SILENCE_SECONDS=35
```

Бесплатный ключ: https://aistudio.google.com/apikey (карта не нужна). Актуальные имена моделей смотри в AI Studio. Другие провайдеры (OpenRouter, Groq и т.д.) подключаются сменой `AI_BASE_URL` и `AI_MODEL`.

## Админ-режим

В личке с ботом: `/keysi <пароль>` → выбираешь чат → всё, что пишешь боту, уходит в чат от его имени. Кнопка «Выйти из чата» возвращает к списку, `/keyout` снимает доступ.

## Запуск локально

```bash
python -m venv .venv
pip install -r requirements.txt
python bot.py
```

Перед запуском установи переменные окружения.

## Telegram: важно для групп

Чтобы бот видел обычные сообщения в группах и мог отвечать без @упоминания, отключи Privacy Mode у бота через BotFather (`/setprivacy` → Disable) либо используй права, позволяющие боту получать нужные сообщения.

## Northflank

Создай сервис из GitHub-репозитория, выбери Python/Buildpack и команду запуска:

```bash
python bot.py
```

В Secrets/Environment Variables добавь `TELEGRAM_BOT_TOKEN`, `AI_API_KEY` и `ADMIN_PASSWORD`. Реальные значения в репозиторий не загружай.

## Безопасность

Если ключи когда-либо были опубликованы, их следует заменить/отозвать у соответствующего провайдера. Этот проект намеренно содержит только пустые placeholders.


## Telegram Business (режим управления разрешёнными чатами)

1. В `@BotFather` открой настройки своего бота и включи **Business Mode**.
2. В Telegram Premium-аккаунте открой **Настройки → Telegram для бизнеса → Чат-боты**, выбери своего бота и подключи его.
3. Разреши боту доступ только к тем личным чатам, которыми он должен управлять, и выдай право отвечать на сообщения (`Reply`).
4. В нужном подключённом чате отправь `/ai` — ответы ИИ включатся только для этого чата.
5. Отправь `/off` — ИИ перестанет отвечать в этом чате. Переключатели сохраняются в SQLite и переживают перезапуск процесса.

Бизнес-ответы отправляются через официальный Telegram Business Bot API от имени подключённого бизнес-аккаунта. Telegram ограничивает отправку сообщений правами подключения; в частности, ответ может быть недоступен для чатов без недавнего входящего сообщения (обычно действует окно последних 24 часов). Бот не получает доступ к чатам, которые владелец не разрешил в настройках подключения.

### Необходимые ключи

- `TELEGRAM_BOT_TOKEN` — токен от `@BotFather`.
- `AI_API_KEY` — API-ключ Gemini AI Studio: https://aistudio.google.com/apikey.
- `ADMIN_PASSWORD` — придумай длинный пароль для старого админ-режима `/keysi` (если он нужен).

`AI_BASE_URL`, `AI_MODEL` и `AI_FAST_MODEL` можно оставить из `env.example`, если выбранная модель доступна твоему API-ключу. Не публикуй токены и ключи в GitHub и не отправляй их в чат.
